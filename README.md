# Panel Administrativo Web - Sistema Carwash

Interfaz web diseñada específicamente para el área de caja y gerencia del Carwash. Permite gestionar catálogos (vehículos, servicios), visualizar reportes de ganancias y administrar accesos de usuarios de manera intuitiva.

## Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript
* **Diseño UI:** Bootstrap
* **Conexión:** Fetch API

## Encargado de Desarrollo

## Estructura del Proyecto
* `/index.html` - Pantalla de inicio de sesión.
* `/dashboard.html` - Panel principal de administración.
* Comunicación exclusiva con el repositorio `carwash-api-backend`.
